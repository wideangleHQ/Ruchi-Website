# Project Goals & Design Direction

Sourced from [docs/RUCHI-FOODLINE-DESIGN-KNOWLEDGE.md](../05-design-system/original-design-brief.md), the project's design brief (§01), which is treated throughout this handbook as **intent**, cross-checked against the actual implementation — see [Known Gaps](../11-roadmap/known-gaps.md) for where the two diverge.

## Intended design language

The brief calls for a **premium editorial ecommerce aesthetic**:

- Premium but approachable
- Editorial and product-led
- Modern Indian FMCG
- Clean and spacious
- Image-driven
- Warm and trustworthy
- Minimal without feeling empty
- Highly polished on mobile and desktop

> "The reference establishes the layout philosophy, not a literal template to copy. The Ruchi implementation must remain original and unmistakably Ruchi Foodline." — design brief §01

## Core visual philosophy

**Editorial storytelling + premium ecommerce + Indian food identity.**

The brief frames the customer journey as:

**DISCOVER → EXPLORE → TRUST → SHOP → INSPIRE → CONVERT**

## Design personality (brief §38)

| Trait | Achieved through |
|---|---|
| Rooted | Playfair Display + heritage storytelling |
| Modern | Poppins + clean layouts |
| Fresh | White space + green |
| Bold | Controlled red campaign moments |
| Trusted | Structured product presentation, clear information |
| Premium | Photography, typography, spacing, restraint |

**Verification note:** the "Modern" pillar's font half is not currently achieved as specified — the brief calls for Poppins as the UI font, but the implementation uses Plus Jakarta Sans. See [Typography](../05-design-system/typography.md).

The ecommerce objective this design language serves is described in [Project Overview](project.md).
