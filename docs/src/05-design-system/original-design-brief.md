# Ruchi Foodline --- Design Knowledge & UI System

## 01. Design Direction

Ruchi Foodline should use a **premium editorial ecommerce aesthetic**
inspired by the supplied reference design.

The design language should feel:

-   Premium but approachable
-   Editorial and product-led
-   Modern Indian FMCG
-   Clean and spacious
-   Image-driven
-   Warm and trustworthy
-   Minimal without feeling empty
-   Highly polished on mobile and desktop

The reference establishes the **layout philosophy**, not a literal
template to copy.

The Ruchi implementation must remain original and unmistakably Ruchi
Foodline.

### Core visual philosophy

**Editorial storytelling + premium ecommerce + Indian food identity**

The website should guide the customer through:

**DISCOVER → EXPLORE → TRUST → SHOP → INSPIRE → CONVERT**

Avoid generic Shopify-template patterns wherever a more intentional
branded composition is possible.

------------------------------------------------------------------------

# 02. Typography System

Use exactly these primary fonts:

## Display Font --- Playfair Display

Use **Playfair Display** for:

-   Hero headlines
-   Major editorial headlines
-   Brand storytelling headings
-   Collection campaign titles
-   Important section titles
-   Large promotional statements

Character:

-   Elegant
-   Heritage-driven
-   Premium
-   Editorial
-   Sophisticated

Use it selectively. Large serif typography should create visual moments,
not dominate every section.

## UI Font --- Poppins

Use **Poppins** for:

-   Navigation
-   Product names
-   Prices
-   Buttons
-   Labels
-   Metadata
-   Descriptions
-   Forms
-   Filters
-   Utility text
-   Footer navigation

Character:

-   Modern
-   Friendly
-   Clean
-   Highly readable

### Typography rule

**Playfair Display = emotion and storytelling**

**Poppins = usability and commerce**

Never use multiple unrelated font families.

### Suggested hierarchy

Hero display: - Playfair Display - Large - Strong contrast - Tight
line-height

Section heading: - Playfair Display - Medium/semibold - Controlled width

Body: - Poppins - Regular - Comfortable line-height

Navigation: - Poppins - Medium - Small/medium size

Labels: - Poppins - Medium/semibold - Uppercase when useful - Slight
letter spacing

Buttons: - Poppins - Medium/semibold

The primary palette is:

**RED + GREEN + BLACK + WHITE**

The palette must be controlled carefully.

Use for:

-   Primary brand accents
-   Primary CTAs where appropriate
-   Active states
-   Trust indicators
-   Brand highlights
-   Selected states

## Deep Green

`#0E6337`

Use for:

-   Strong brand sections
-   Footer
-   Dark promotional areas
-   High-contrast branded surfaces

## Brand Red

`#C62828`

Use for:

-   Promotional campaigns
-   Festive accents
-   Important secondary CTAs
-   Sale/limited-edition messaging
-   Attention moments

Red should be an accent, not the dominant background of the entire
website.

## Deep Red

`#9F1F24`

Use sparingly for:

-   Strong campaign areas
-   Hover/active states where appropriate
-   Festive visual treatments

## Black / Charcoal

`#171717`

Use for:

-   Primary text
-   Strong navigation
-   Headings when required
-   High-contrast UI

## White

`#FFFFFF`

Use extensively to create the clean premium feel.

## Soft Neutral

`#F7F6F2`

Use for:

-   Editorial backgrounds
-   Alternating sections
-   Soft content surfaces
-   Product-image framing

## Soft Green

`#EEF6EC`

Use for:

-   Light brand panels
-   Supporting cards
-   Selected states
-   Subtle backgrounds

## Border

`#E3E3DE`

Use for:

-   Product card borders
-   Inputs
-   Dividers

### Color ratio

The website should visually lean toward:

**White / light neutral → primary**

**Black / charcoal → typography**

**Green → brand interaction**

**Red → strategic emphasis**

Do not use red and green equally everywhere. This will make the
interface visually noisy.

# 04. Shape & Corner System

Curved corners are a defining part of the UI.

## Standard Radius

**12px**

Use 12px consistently for:

-   Product cards
-   Image cards
-   Buttons
-   Inputs
-   Search fields
-   Promotional blocks
-   Content panels
-   Collection cards

Avoid mixing many radius values.

### Image treatment

Large editorial images should generally use:

**12px radius**

Smaller supporting imagery can use the same system.

Avoid excessive pill-shaped elements.

Pills should only be used for:

-   Small badges
-   Tags
-   Filters
-   Status indicators

------------------------------------------------------------------------

# 05. Layout Philosophy

The reference uses a centered, editorial ecommerce layout.

Ruchi should follow:

**Wide desktop canvas + controlled content width + generous whitespace**

Recommended content container:

-   Max width around 1200--1320px
-   Fluid horizontal padding
-   Strong alignment between sections

The layout should never feel stretched edge-to-edge unless a section
intentionally uses a full-bleed image.

### Section rhythm

Use clear visual breathing room between major sections.

Preferred structure:

**Section label** ↓ **Editorial heading** ↓ **Supporting copy** ↓
**Content / product grid**

Avoid placing every section immediately against the next.

The homepage should follow an editorial storytelling rhythm inspired by
the supplied reference.

2.  Hero
3.  Brand introduction
4.  Category showcase
5.  Bestsellers / featured products

# 07. Header

The header should be:

-   Minimal
-   Compact
-   Premium
-   White or very light
-   Strongly aligned
-   Easy to scan

### Desktop

Left: **Ruchi Logo**

Center: - All Products - Categories - About Us - Contact - Other
approved navigation

Right: - Search - Account if implemented - Cart

### Mobile

Left: Menu

Center: Logo

Right: Search + Cart

Use a sticky header only if it improves usability.

------------------------------------------------------------------------

# 08. Hero System

The hero should be the strongest visual moment on the homepage.

Use:

-   High-quality Ruchi product/food photography
-   Strong Playfair Display headline
-   Short Poppins supporting copy
-   One primary CTA
-   Optional secondary CTA
-   Subtle motion

### Hero composition

The reference demonstrates a large visual hero with:

**Large image** + **Editorial headline** + **Short copy** + **CTA**

Ruchi should follow this principle.

Do not overload the hero with multiple competing messages.

### Hero CTA

Primary CTA should be obvious and accessible.

Preferred examples:

`SHOP NOW`

`EXPLORE PRODUCTS`

`DISCOVER RUCHI`

Use real destinations.

Do not create fake links.

Use asymmetry intentionally.

-   Ingredient close-ups
-   Warm editorial lifestyle imagery

# 25. Animation System

Animation should support storytelling and usability.

Use subtle:

-   Fade-in
-   Upward reveal
-   Image scale
-   Counter animation
-   Hover transitions
-   Button transitions
-   Cart transitions

Preferred timing:

Fast and natural.

Avoid:

-   Long cinematic delays
-   Excessive parallax
-   Constant movement
-   Animations on every element

### Accessibility

Respect:

`prefers-reduced-motion`

If reduced motion is enabled, simplify or remove non-essential
animations.

------------------------------------------------------------------------

# 26. Responsive Design

The reference is strongly mobile-oriented in composition.

Ruchi must be designed mobile-first and then expanded for larger
screens.

## Mobile

-   Single-column storytelling
-   2-column product grids where readable
-   Horizontal category carousels when useful
-   Compact header
-   Large readable headings
-   Full-width CTA buttons where appropriate
-   Comfortable spacing

## Tablet

-   Balanced 2--3 column grids
-   Controlled hero composition
-   Moderate whitespace

## Desktop

-   Editorial wide layouts
-   3--4 column product grids
-   Asymmetric image sections
-   Strong typography hierarchy

## Large desktop

Do not simply stretch content.

Use max-width containers.

------------------------------------------------------------------------

# 27. Spacing System

Use a consistent spacing scale.

Suggested base:

4px

Then:

8px 12px 16px 24px 32px 40px 48px 64px 80px 96px

Major sections generally need:

64--96px vertical spacing on desktop.

Mobile:

40--64px depending on section importance.

Avoid excessive whitespace inside product cards.

------------------------------------------------------------------------

# 28. Grid System

Use a responsive 12-column conceptual grid on desktop.

Typical:

-   3-column category layouts
-   4-column product layouts
-   2/3 split editorial layouts
-   1/3 + 2/3 promotional compositions

On mobile collapse intentionally.

Do not preserve desktop columns at the cost of readability.

------------------------------------------------------------------------

# 29. Visual Hierarchy

Every section must have one clear focal point.

Hierarchy should normally be:

1.  Image / primary visual
2.  Headline
3.  Product or collection name
4.  Supporting information
5.  CTA

Avoid giving every element equal visual weight.

------------------------------------------------------------------------

# 30. Indian Brand Expression

Ruchi should feel Indian without becoming visually stereotypical.

Use Indian identity through:

-   Food photography
-   Spice textures
-   Ingredient imagery
-   Warm editorial compositions
-   Subtle heritage motifs
-   Festive campaigns
-   Storytelling
-   Authentic product presentation

Avoid filling the UI with:

-   Decorative patterns everywhere
-   Excessive ethnic ornaments
-   Too many colors
-   Heavy traditional motifs

The target is:

**MODERN INDIAN FOOD BRAND**

not:

**TRADITIONAL-THEME WEBSITE**

------------------------------------------------------------------------

# 31. Trust & Premium Feel

Premium perception comes from consistency.

Prioritize:

-   High-quality images
-   Excellent typography
-   Consistent spacing
-   Clean product cards
-   Strong alignment
-   Restrained colors
-   Subtle motion
-   Clear CTAs
-   Fast loading

Do not attempt to create a premium feel through excessive effects.

------------------------------------------------------------------------

# 32. Accessibility

Maintain:

-   Strong contrast
-   Semantic HTML
-   Keyboard navigation
-   Visible focus states
-   Proper alt text
-   Accessible buttons
-   Accessible form labels
-   Touch-friendly controls
-   Reduced-motion support

Do not sacrifice accessibility for aesthetics.

------------------------------------------------------------------------

# 33. Performance Rules

The visual design must not compromise performance.

Use:

-   Next.js Image
-   Correct image dimensions
-   Lazy loading below the fold
-   Priority only for critical hero media
-   Server Components where possible
-   Minimal Client Components
-   Efficient Shopify GraphQL queries
-   Proper caching
-   Avoid unnecessary JavaScript

The first viewport must load quickly.

------------------------------------------------------------------------

# 34. Shopify Data Rules

The frontend is a presentation layer.

Shopify remains the source of truth for:

-   Products
-   Variants
-   Prices
-   Inventory
-   Collections
-   Cart
-   Checkout
-   Orders
-   Customers
-   Discounts

Never hardcode:

-   Product prices
-   Inventory
-   Product names
-   Variant IDs
-   Product availability

unless the value is intentionally static marketing content and verified.

# 37. Do / Don't

## DO

-   Use Playfair Display for editorial moments
-   Use Poppins for UI
-   Maintain red/green/black/white identity
-   Use 12px corners
-   Use generous whitespace
-   Use real product imagery
-   Use Shopify data dynamically
-   Use subtle animation
-   Keep layouts editorial
-   Design mobile intentionally
-   Maintain consistent spacing

## DON'T

-   Use random colors
-   Mix unrelated fonts
-   Use excessive rounded pills
-   Add heavy shadows
-   Overuse gradients
-   Over-animate
-   Use generic stock imagery
-   Hardcode Shopify product data
-   Build duplicate commerce systems
-   Create unnecessary UI sections
-   Copy the reference website literally

Every page should feel like it belongs to the same design system.

The customer should immediately recognize:

**This is Ruchi Foodline.**

Even when moving between:

Homepage → Collection → Product → Cart → Checkout

The visual language should remain consistent.

The final experience should be:

**Premium enough to feel aspirational.**

**Simple enough to shop effortlessly.**

**Indian enough to feel authentic.**
